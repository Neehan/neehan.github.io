Essay Mate is a free ChatGPT plugin created by [Adib Hasan](https://adibhasan.com) to help high school students improve their college application essays. There are no payments, purchases, or paid upgrades from Essay Mate. Access through ChatGPT is subject to OpenAI's availability, account requirements, and any applicable plan limits.

[How to use it](#how-to-use-it) · [Support](#support) · [Privacy policy](#privacy-policy) · [Terms of use](#terms-of-use)

## How to use it


1. Open [**Plugins**](https://chatgpt.com/plugins) in ChatGPT on the web (or open **Plugins** in the desktop app), and search for **Essay Mate**.
2. Open its details and select the **+** button to install it.
3. Start a new chat, type **@Essay Mate**, and select the plugin from the menu.
4. Share your draft and the essay prompt, or ask for help brainstorming. Include the word limit if there is one.

For example: “Help me improve this college application essay while keeping my own voice. The prompt is … and the word limit is 650.”

See [OpenAI's guide to installing and using plugins](https://learn.chatgpt.com/docs/plugins) for more help.

## How it helps

Share a draft or ask for help brainstorming. Essay Mate provides candid feedback on storytelling, personal voice, structure, and clarity, with paragraph-by-paragraph suggestions and practical next steps. Its goal is to help you express your own experiences more effectively.

Feedback is generated by AI, not personally reviewed by Adib. Ratings are writing feedback, not predictions of admission chances.
